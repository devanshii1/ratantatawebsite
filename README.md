# Ratan Tata — A Life in Business

A simple responsive student website about Ratan Tata, built with HTML, CSS, and JavaScript.

## Files
- `index.html` — the website, including styles and interactive venture cards
- `assets/` — place any image files used by the website here

## Run locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `README.md`, and the `assets` folder if you add images.
3. In the repository, open **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.
