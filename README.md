# Ratan Tata — A Life in Business

A responsive, interactive student website exploring the life, leadership, business journey, and legacy of **Ratan Tata**, one of India's most respected business leaders.

## 🌐 Live Website

[**Visit Ratan Tata — A Life in Business**](https://devanshii1.github.io/ratantatawebsite/)

*If the link does not open, enable GitHub Pages using the instructions below.*

## 📖 About the Project

This project presents Ratan Tata's journey in a clear, student-friendly format. It highlights key milestones in his life, companies associated with the Tata Group, his achievements, and the lessons his leadership offers.

## ✨ Features

- **Responsive design** — adapts to desktop and mobile screens.
- **Interactive navigation** — jump between sections of the website.
- **Life timeline** — explore important milestones in chronological order.
- **Searchable company directory** — find and filter companies associated with the Tata Group.
- **Company connection map** — explore relationships between businesses and the wider group.
- **Achievements and lessons** — understand his contributions and leadership principles.
- **Sources section** — links to references for further reading.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 📁 Project Files

- `index.html` — website structure, styling, and interactive features.
- `ratan-tata-3.webp` — portrait image used by the website.
- `README.md` — project documentation.

## 💻 Run Locally

1. Download or clone this repository.
2. Keep `index.html` and `ratan-tata-3.webp` in the same folder.
3. Open `index.html` in your web browser.

## 🚀 Publish with GitHub Pages

1. Open the repository's [GitHub Pages settings](https://github.com/devanshii1/ratantatawebsite/settings/pages).
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose the `main` branch and the `/ (root)` folder.
4. Click **Save**.
5. Wait for GitHub Pages to finish deploying the website.
6. Open the live website: [https://devanshii1.github.io/ratantatawebsite/](https://devanshii1.github.io/ratantatawebsite/).
